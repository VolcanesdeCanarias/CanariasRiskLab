# Identidad oficial pendiente

Colocar aquí el archivo oficial autorizado de Volcanes de Canarias (SVG sanitizado, PNG o WebP) y su atribución/licencia. No hay archivo oficial en esta entrega. Añadir su nombre exacto a la allowlist del Blueprint y usar alt adecuado antes de activarlo; no servir todo el directorio ni aceptar SVG no revisado. El monograma R de la interfaz identifica el producto, no recrea el logotipo de la entidad.
