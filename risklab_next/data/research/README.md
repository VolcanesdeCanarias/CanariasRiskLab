# Histórico oficial del caso piloto

Los tres archivos de usgs-tenerife-2000-2026 son bytes originales de respuestas USGS FDSN. Ver manifest.json con URLs, ventana/caja consultadas, política de datos, fecha de generación publicada y hashes. GeoJSON/CSV/count reconciliados:181 filas, red us. No sobrescribirlos al refrescar: crear versión nueva. La consulta no acredita detección completa ni homogénea de microsismos regionales. La ventana es2000–2026 excluido; registros retornados se concentran en2000–2008 y hay uno en2019. No interpreta ceros como inactividad. No usar el archivo privado Earth/KMZ como validado por semejanza.

teide-context.json contiene síntesis propias de fuentes primarias y enlaces, fechas de consulta, publicación desconocida explícita, relaciones tipadas y carencias. No copiar cartografía/MDT/logotipos no autorizados. La referencia CNH no tiene geometría validada; no se rellena con una coordenada manual ni se presenta como instalación crítica/operativa.
