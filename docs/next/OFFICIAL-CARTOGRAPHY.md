## Evidencia de ejecución

Archivos `review01/services-probe.json` y `review01/getmap-probe.json` registran resultados, URLs, tipo y firma PNG. Se verifican tres productos WMS, no todos sus niveles/territorios. La revisión visual real con IGN adquirió 20 eventos y seleccionó 4 en 24h; cargó 24 imágenes en la ejecución archivada. Una ejecución anterior tuvo respuestas HTTP502 parciales; no se ocultan ni se atribuyen a una causa no comprobada. El estado de base informa carga parcial/fallida sin convertir los sismos en cero.

En cloud se utilizó el transporte de revisión `RISKLAB_TILE_PROXY=1`: Playwright API reenvía las respuestas auténticas IGN a Chromium a través del proxy configurado, manteniendo TLS verificado. No sustituye imágenes ni datos y no forma parte de producción. Las pruebas offline abortan red externa y se rotulan como fixtures. La descarga masiva/offline de teselas no está implementada ni autorizada implícitamente.

## Relieve: decisión explícita

No se habilita una base «relieve 3D» ficticia. La cartografía topográfica puede contener sombreado o batimetría dibujada, pero sigue siendo imagen sobre el elipsoide. El componente 3D admite una malla numérica local documentada con LOD de representación, sin rellenar nodata, multiplicar alturas o hacer pasar la malla reducida por precisión nativa. Ver [importación de MDT](TERRAIN-IMPORT.md). Sin ese archivo, el estado visible dice que no existe MDT importado. No se ha resuelto todavía la referencia vertical terrestre/hipocentral/batimétrica.
